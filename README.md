# Codomax Internship – Module 02

## Python Mini Project: Python Quiz Application

### Project Description
The Python Quiz Application is a beginner-level project developed using Python. It allows users to participate in a multiple-choice quiz, check their answers and calculate their final scores automatically.

### Features
- Accepts the user's name.
- Displays multiple-choice questions.
- Provides four options for each question.
- Checks correct and incorrect answers.
- Validates user input.
- Calculates the final score.
- Displays percentage and performance.

### Technologies Used

- Visual Studio Code

- While Loop

1. Install Python.

3. Open quiz_app.py.

5. Enter your name.
6. Answer the quiz questions.
